# Sprint 5 · 分镜、分章与矩阵

- 分镜由正式版本的配图计划派生，图位使用任务、文章版本、顺序的组合键。作者可复制 image2 描述，上传反馈绑定原版本；已切版或同时修改图位会拒绝旧写入。图片仅接受原有栅格格式，离线线框为界面 SVG。
- 深度长文沿用生产队列。大纲以稳定章节键生成，每章独立检索，在授权池中选依据，调用按既有研究、长文路由及预算核算。各章全部成功才交付文章。单章重写产生待保存草稿，沿用草稿 CAS。文章段落 ID 不参与正文序列化或审核 UTF-16 偏移。
- 矩阵在预检给出来源提示，提交在持锁事务复核；同一品牌跨动态账号匹配历史、在途、排期及同批内容。作者可显式登记同题实验。成稿比较从真实 SQLite 账号和正式版本读取。
- GEO 结果仅依文案证据给出四类建议。生产装配冻结账号、规范与资料索引，记录来源、去重和冲突。

每章完成后按任务、研究版本与输入摘要保存检查点。失败后可按原批次继续，已完成章只在资料仍获授权时复用。当调用回执未知时，保留原队列的禁止自动重发规则。分章属于原生成阶段的一跳，各章分别计入请求和 Token 限额。自动审核和修订仍沿用原有跳数、租约和预算。单章人工改写在模型前后校验正式版本及草稿修订；未改正文块保留原 ID，修改后的段落仅继承仍逐字匹配的出处。

矩阵使用全角归一化及字词片段重叠判定，命中提示列出字段，作者可登记实验目的后继续。正常提交和离线演练都使用同一事务检查。计划日期已指定的未提交草稿按同日查找，历史和在途按相关内容查找。跨账号并排视图按冻结的原选题归组，并支持选用不同正式文章版本。

分镜回填限制为 PNG、JPEG 和 WebP。切换目标预览不会改变已回填图片的文件或生成第三方请求；图位图片由作者按当前版本确认。

## 离线复验

在公开工作树运行以下 PowerShell 命令。数据目录使用新名称，避免复验动作和已有稿件共用账号。

```powershell
$env:STUDIO_NEXT_DIST_DIR = '.next/sprint5-final'
$env:PORT = '3788'
$env:STUDIO_DEMO_MODEL_PORT = '3787'
$env:STUDIO_DATA_DIR = Join-Path $env:TEMP 'public-sprint5-fresh'
npm run build
node scripts/start-production.mjs --demo
```

另开终端运行自动复验。脚本在离线实例新建两个动态账号，通过生产队列生成三章长文，实测并发防撞、改写、分镜回填、ZIP、同题对比和 GEO。

```powershell
$env:STUDIO_SPRINT5_URL = 'http://127.0.0.1:3788'
$env:STUDIO_SPRINT5_EVIDENCE = Join-Path $env:TEMP 'public-sprint5-evidence'
node scripts/verify-sprint5-workspace.mjs
```
