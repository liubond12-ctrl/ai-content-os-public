# v1.0 生产就绪契约

| 边界 | 规则 |
| --- | --- |
| 夜间初筛 | 按账号画像和只读来源调用本机轻量模型，输出 0–100 整数。默认门槛 75。失败或无合法回执时不提交对应写稿任务。 |
| 每日预算 | 北京时间，统一用人民币微元。已确认估算与未结算预留同口径合计。在途和无回执的调用保留上限，未知定价阻断自动请求。80% 后可降级的阶段用明确配置的轻量模型；缺失或不可达时暂停相应自动调用。100% 不再接受自动调用，按日聚合预算提醒。 |
| 通过快车道 | 飞书审批的正式版本评分至少 85 且无未决分歧时，审批事务登记任务。后台逐渠道处理，仅生成独立派生稿并执行词表预检。未知调用结果等待人工核对，保留人工复制、定稿与发布。 |
| 专题 | 账号、归一化专题标签、正整数集数唯一。只按合法前序排除该系列造成的重复命中。前序可读摘要冻结到提交快照，模型只能当资料使用。 |
| 探活 | 区分本机实测、心跳观察、配置就绪和待授权验证。拒绝运行远端写入或携带凭证的探测。 |
| 效果对比 | 在同一离线样本上计算两种配置的实测指标，保留分母、输入和可复验命令。合成样本标明模拟边界，缺测显示缺测。 |
