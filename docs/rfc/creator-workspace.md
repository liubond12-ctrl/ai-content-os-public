# 创作者工作台与状态反馈

创作者从待办开始，进入正文修稿，再从成品区复制或配图。系统机房提供原有的运行记录和配置。既有链接、来源返回、数据库、模型授权与接口字段继续沿用。

| 界面 | 映射 |
| --- | --- |
| 今日待办 | 显示当前待处理稿件，在「今日待办」标题下用四张可点击卡呈现真实早报、待发布、待填数据和可启用经验数。保留来自首页的稿件返回锚点。 |
| 写稿与精修 | 原新建单篇、批量、自由文章与编辑。 |
| 历史文章 | 原文章清单、需求草稿、全部任务与搜索、历史批次。旧筛选参数和返回锚点沿用。 |
| 热点与巡航 | 今日热点与原巡航入口。早报和选题筛选结果优先，运行参数按需查看。 |
| 账号与素材 | 账号、写作规范、质量标准、参考库、飞书资料与发布复盘。 |
| 系统机房 | 独立于五项主导航，放在左栏底部。进入运行检查、费用熔断预算、模型分工、治理、资料使用、备份和离线验收。 |
| 审核 | 有事实风险或分歧时主动显示；普通检查用胶囊打开。最近结论与存档仍可查看。 |
| 规则升级 | 作者区只呈现重评分数达到 80% 且当前可合并的规则。拦截与已失效提案在系统入口留档。 |
| 可收回动作 | 忽略建议延迟 5 秒写入，窗口内撤销无需回滚；稿件归档、图位清空需确认，保留现有版本保护和写入事务。 |

版式沿用原工作台的阅读宽度。导航与工具属于同一张编辑台，纸面底色 #f7f7f3、主字 #202924、主操作 #23513e、边界 #cbd4cc、确认落笔的暖光 #f5da9b；标题用本机衬线中文回退，正文和工具保留系统字体。动效映射到提交回执、卡片收起、展开与定位，统一 140/220 ms，已落盘的原文替换暖光 600 ms。减少动态直接呈现终态。

桌面左栏吸顶，机房入口在左栏底部。窄屏使用单个工作空间菜单，菜单展开后占用文档空间并限制高度。链接跳转时收起菜单，页面底部和软键盘上方无固定操作条。首页显示设置归入首页操作区。
