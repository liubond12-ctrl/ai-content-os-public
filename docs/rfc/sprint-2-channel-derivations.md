# Sprint 2 三端分发与合规雷达

本轮范围按最新 Sprint 2 指令执行。生产账号防撞车、飞书审批及视觉卡片对接沿用总规划各自的施工安排。

| 对象 | 契约 |
| --- | --- |
| 来源 | taskId 与 articleVersion 精确绑定已保存的正式文章版本。生成读取快照，编辑与复制使用渠道草稿。未保存的母稿修改不会发给模型。 |
| 渠道形态 | 小红书、抖音口播、抖音短图文、公众号长文。抖音两种形态各自持久化。 |
| 派生版本 | SQLite 使用 (task_id, article_version, variant, revision) 复合主键，生成或保存追加新修订，基于修订号作事务并发检查。每条修订记录派生规则版本。 |
| 小红书 | 3 条标题（每条最多 20 个字，按 Unicode 字符计数）、分段正文、8 条标签、3 组以作者身份发布的问答。 |
| 抖音 | 口播含 3 条开头钩子和带画面、重音停顿标注的逐字稿。短图文独立保存标题、逐页文案和 CTA。 |
| 公众号 | 标题和有序内容块（段落、引用、重点、步骤）及文末 CTA。渲染器转义所有字段，输出固定标签和内联样式。剪贴板同时提供 text/html 与 text/plain。 |
| 风控与转化 | 当前编辑内容实时扫描，显示词面命中、字段、搜索词覆盖和行动引导完整度。词库为本地预检，命中交给作者结合语境复核。 |
| API | GET/POST /api/derivations。生成复用现有模型授权、预算及回执，云端另行确认。保存与复制无需模型。 |
| 离线 | 沿用 --demo HTTP 模拟模型，提供三端与两种抖音形态，带明确的虚构风险样例。 |

## 离线验收

`scripts/verify-sprint2-channels.mjs` 连接已启动的 `--demo`。默认地址为 `http://127.0.0.1:3698`，也可用 `STUDIO_SPRINT2_URL` 指定。将 `STUDIO_SPRINT2_EVIDENCE` 设为本地验收目录，脚本把截图、母稿链接、剪贴板格式和左右滚动测量写到该目录。公众号的真实后台粘贴效果需单独核对。
