# AI Content OS 零冲突演进总规划（Sprint 1 ~ Sprint 5）

## 执行规范

人类架构师确定产品方向、交互范式和验收标准。Codex 负责数据契约、实现、离线演示和回归。执行铁律以根目录 `AGENTS.md` 为准。

先在 `src/types/` 和 `docs/rfc/` 落定类型与字段映射，再接入真实状态机。沿用现有数据、权限与状态边界。每个 Sprint 更新适用的离线演示、测试和评估用例，运行 `npm test` 与 `npm run build`，报告可复现的验收路径。

## Sprint 1 · 完成会诊与精修闭环

- 验收编辑页右侧的专家卡片、草稿处理进度分、仲裁摘要、并排分歧方案和讨论时间线。
- 验收定位原文、局部改写、采纳、自定义合并与结尾生成插入。编辑动作绑定审核版本与草稿修订号，草稿修改与处理记录同事务保存。正式稿件质量由正式审核确认。
- 隔离 `--demo` 的知识与向量索引。走实际队列和本地模拟模型，覆盖「会诊演练」低分、冲突、修改和旧分歧场景。验证后提交本地 Git 版本。

## Sprint 2 · 三端分发引擎与合规雷达

- 从已保存的正式母稿生成可独立编辑的小红书、抖音口播、抖音短图文与公众号长文。按母稿版本和渠道形态隔离修订。
- 提供交付复制及本地合规预检，展示风险词、搜索词、行动引导和钩子的缺项。

## Sprint 3 · 夜间无人值守预生产与飞书早报翻牌（已完成离线验收）

- 复用热点、获授权飞书资料、生产队列与多 Agent 审核。按账号画像和定时策略运行，记录预算、质量门槛及淘汰原因。
- 扩展飞书通知 outbox、回调 inbox 和身份校验。早报按日归集候选，支持通过进入三端分发或打回重跑。处理重复、乱序、过期和版本变化。
- 定稿或审批后更新台账。多维表格使用独立写权限、字段白名单和记录映射。记录失败与未知结果，先核对再重试。用隔离模拟传输验收。
- 网页确认定稿或处理该版分歧时，同一事务登记通知 `resolve`。飞书更新原卡为「已在工作台处理」，并拒绝晚到的未处理回调。
- 自动生成、每轮正式审核和每次自动修订记一跳，专业角色共用该轮审核的一跳。根任务及打回重跑共用服务端追加账本，上限 8 跳。用完额度仍需自动推进时转人工并通知飞书。
- 今日热点与获准飞书同步文本作为只读资料进入上下文。系统控制指令、目标模型、账号身份和授权由工作台决定。

## Sprint 4 · cheat-on-content 校准闭环与原子素材乐高库

- 定稿时封存不可篡改的 `BlindPrediction` 盲预测单，绑定账号、母稿正式版本和当时的规则版本。保留初稿到定稿的 Diff 作为写法证据。
- 发布登记后投递持久化 `later: +72h` 延迟唤醒事件，触发 T+3d 复盘。将授权发布数据与预测、母稿及渠道版本对齐；复盘回执记录实测值及缺失项。
- 升级规则前用新规则对历史样本全量重打并校验。排序一致率达到 80% 才允许放行并清理过期旧规则，保留评估和规则版本的追溯记录。
- 仅从实战验证的高分定稿萃取可独立检索和拼装的 Hook、真实案例、模型或方法论、CTA。继承来源权利、用途和账号隔离。
- 在 `provider.ts` 引入声明式多模型分工路由，由工作台配置各角色用途、模型、权限与预算。

## Sprint 5 · 视觉导演分镜、深度长文与矩阵协作

- 生成供外部 `image2` 使用的导演分镜指令卡，支持 Ctrl+V 将结果回填到对应图位，沿用附件和图位版本确认，复用 `content-package.ts` 打包 ZIP。
- 用稳定的 `sectionId` 组织深度长文，分章检索和生成，保留出处、章节版本及全文结构。
- 将全链路矩阵防撞车接入排期日历，联查历史成稿、在途队列和待发草稿。提供不同生产账号正式成稿并排对比，显示命中的标题、论点、开头、素材和行动号召。保留主动同题实验例外。
### 延续事项 · 实时策划与矩阵防撞车

- 复用生产队列与专业审核状态，显示初审、分歧讨论及裁决进度。按实际角色结果更新视图。
- 复用现有创作输入，先给三组差异化的切入角度、开头和大纲，作者确认后沿用正式生产队列生成全文。
- 防撞车必须同时扫描**历史成稿、队列在途任务、待发草稿**。按品牌、账号、平台及发布窗口定义碰撞范围，以标题、论点、开头、案例、行动号召和素材说明命中理由。预检展示冲突，提交时事务复核。主动同题实验记录为明确例外。
- 补全**生产账号成稿的并排对比视图**。以稿件及正式版本为单位，比较不同账号的开头、论据和行动号召，支持按权限借鉴局部写法。现有上下文对比仍用于查看规则和配置差异。
